# 目的

- 個人でPCまたはスマートフォンを使い、考えや当日の作業を自由に置きたいときに使う付箋ボード。
- 付箋を追加して位置を変えたい。なぜなら、優先順位や考えのまとまりを視覚的に整理したいから。
- 思いつきをすぐ記録したい。なぜなら、別のアプリを開く前に忘れないようにしたいから。
- ブラウザを閉じても付箋を残したい。なぜなら、次回も同じボードから作業を再開したいから。

# やること（MVP）

- 1画面のボード上に、テキスト付きの付箋を新規作成する。
- 付箋の本文を入力・編集する。
- 付箋上部の持ち手をマウスまたは指でドラッグし、好きな位置へ移動する。
- 付箋を削除し、内容と位置をブラウザ内に保存・復元する。
- 新しい付箋は、既存付箋と重ならない空き位置へ配置する。
- 追加機能として、各付箋の色を黄色・水色・ピンク・緑色から選んで変更する。

# やらないこと

- ログイン、複数ユーザー、他の端末との同期はしない。
- 付箋の共同編集、共有リンク、コメント、通知はしない。
- 画像・ファイルの添付、検索、タグ付け、期限設定はしない。
- クラウドへの保存や外部サービスとの通信はしない。

# 扱うデータ

| 項目名 | 種類 | 必須か |
| --- | --- | --- |
| id | 文字列 | 必須 |
| text | 文字列 | 必須（空文字可） |
| x | 数値 | 必須 |
| y | 数値 | 必須 |
| color | 文字列 | 必須 |

# 画面一覧と遷移

- 画面1：付箋ボード。追加ボタン、使い方、保存状態、付箋の一覧を置く。
- 同じ画面内で、追加・編集・移動・削除を完結させる。画面遷移はない。
- 初回は空の案内と「最初の付箋を作る」ボタンを表示する。
- 付箋がある場合は、各付箋に本文入力欄、持ち手、削除ボタンを表示する。

# 使う技術

- 画面：Vite、素のHTML、CSS、JavaScript。
- 保存の仕組み：ブラウザのlocalStorageへJSON形式で保存する。
- 動かし方：`npm install`後に`npm run dev`を実行し、表示されたローカルURLをブラウザで開く。
