# 作る順番

- [x] 1. 付箋ボードの1画面を表示する  
  完了条件：ブラウザで見出し、追加ボタン、空のボードが表示される。  
  理由：以降のすべての機能を同じ画面で確認できるようにするため。

- [x] 2. 付箋を1件追加して画面に表示する  
  完了条件：追加ボタンを押すと、本文入力欄付きの付箋が1枚表示される。  
  理由：最初に中心となるデータと表示の流れを確認するため。

- [x] 3. 付箋本文を入力・編集する  
  完了条件：入力欄へ文字を打つと、表示中の付箋本文が更新される。  
  理由：付箋として最低限必要な記録機能を先に完成させるため。

- [x] 4. 付箋を削除する  
  完了条件：削除ボタンを押すと、対象の付箋だけが画面から消える。  
  理由：不要な記録を戻せる状態を、保存より先に確認するため。

- [x] 5. 付箋をドラッグして移動する  
  完了条件：持ち手をドラッグすると、マウスとタッチの両方で付箋が移動する。  
  理由：入力・削除と独立して、位置の操作だけを確認できるようにするため。

- [x] 6. 新規付箋の重なりを防ぐ  
  完了条件：複数回追加しても、新しい付箋が既存付箋と重ならずに表示される。  
  理由：位置を保存する前に、追加時の位置決めを確定させるため。

- [x] 7. 内容と位置をブラウザに保存・復元する  
  完了条件：再読み込み後も、本文・色・位置が保存前と同じ状態で表示される。  
  理由：保存方式に依存する機能を、基本操作ができた後に追加するため。

- [ ] 8. PC・タブレット・スマートフォンで操作確認する  
  完了条件：1280px、768px、375pxで要素の重なりや横はみ出しがなく、スマホで操作できる。  
  理由：完成判定を利用環境ごとに行い、MVPの品質を確認するため。実機タッチ操作は未確認。

- [x] 9. 付箋の色を変更する  
  完了条件：各付箋で黄色・水色・ピンク・緑色を選べ、再読み込み後も選んだ色が残る。  
  理由：既存の`color`データを活かし、EP17の追加機能を小さく完結させるため。
