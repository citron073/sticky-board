# 実装プラン

## 技術判断

- Viteのvanilla構成を使用する。
- 状態は`localStorage`の`sticky-board-v1`にJSONで保存する。
- ドラッグはPointer Eventsを使い、マウスとタッチを共通実装にする。
- 新規位置はグリッド探索し、既存付箋の矩形と重なる候補を除外する。
- 色変更は各付箋のヘッダーに4色の選択ボタンを置き、既存の`color`項目を更新して保存する。

## データ構造

```js
{ id: string, text: string, x: number, y: number, color: string }
```

## 境界

- クラウド同期・アカウント・共有は実装しない。
- `localStorage`を削除するとデータは失われる。
