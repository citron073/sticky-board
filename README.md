# 付箋ボードアプリ

Vite＋素のJavaScriptで作る、ブラウザ保存型の付箋ボード。

## 起動

```bash
npm install
npm run dev -- --host 127.0.0.1 --port 5174
```

起動後、`http://127.0.0.1:5174/` を開く。

## 操作

- `付箋を追加`：空いている位置に付箋を配置
- 本文欄：メモを編集（自動保存）
- 付箋上部の持ち手：ドラッグ移動
- 4つの丸い色ボタン：黄色・水色・ピンク・緑色へ変更
- `削除`：付箋を削除

データはこのブラウザの`localStorage`に保存される。別端末・別ブラウザには同期しない。

## GitHub Pages

ビルド済みの`gh-pages`ブランチをGitHub Pagesの公開元にする。公開版も付箋データは各利用者のブラウザ内にだけ保存される。
